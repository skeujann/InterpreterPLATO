# Evidence Atlas — 设计说明

本查看器的视觉目标是让读者从双药与靶点，经 BRAF 读到疾病模块，再按需展开完整证据。
采用深炭色导航与路径栏、暖白画布、编辑式标题和单一酸橙色焦点。
不使用外部字体、远程图标、跟踪脚本或装饰性生物学连线。

## 参考与实现

- [Linear — A calmer interface for a product in motion](https://linear.app/now/behind-the-latest-design-refresh)：
  参考降低导航噪声、统一工具栏与弱化容器边框的做法，将视觉注意力留给画布。
- [Linear — How we redesigned the Linear UI](https://linear.app/now/how-we-redesigned-the-linear-ui)：
  参考前后景层次与克制的强调色，而不是逐项复制其界面。
- [Rive — Stage](https://rive.app/docs/editor/interface-overview/stage)：
  参考以舞台为中心、工具围绕画布、属性按需展开的空间组织。

这些参考仅用于设计研究。页面代码、布局、配色组合与 SVG 图标在本项目内实现，
没有打包参考网站截图、品牌标识或收费资产，也不表示获得相关公司的认可。

## 阅读顺序

内置文献实例默认显示两种药物、MEK1 / MEK2、BRAF 和疾病模块，共 6 个节点。
药物在左，MEK 节点居中，BRAF 使用酸橙色作为关键节点；疾病模块位于最右侧。
疾病节点使用淡紫色卡片，清楚标注“疾病模块 / 黑色素瘤”和“BRAF V600 · 文献背景”。
窄画布使用紧凑布局，疾病模块位于下方。阅读终点不表示因果终点。
MEK1 / MEK2 同时保留 MAP2K1 / MAP2K2 标签，便于对应输入 JSON 的基因标识。

“疾病主路径”与“完整网络”只改变显示范围。全部 11 个节点和 20 条边始终保留，
原始属性与来源仍可检查；下载的 JSON 包含完整记录。
自定义布局、视图焦点和可信来源卡片只针对应用内置对象启用，上传文件不能通过同名元数据获得这些行为。

## 证据语义

酸橙色表示阅读焦点，不表示显著性、活性强弱或协同分数。
从左到右只表示阅读顺序。全部边保持无箭头：PPI 使用青绿色实线，靶点关联使用金色虚线，
集合归属使用紫色点线，报告结构使用灰色虚线。
高亮加粗已有边并保留其线型与颜色，避免将不同关系合并为同一种生物学作用。

文献实例没有运行 PLATO、解释器或网络统计，不证明协同、因果或临床机制。
不从路径文字、节点位置或页面布局生成任何新 PPI。

## 使用与验收

详情默认折叠；节点、边、路径和来源均可打开详情。小屏先显示画布，路径和详情依次排列。
保留键盘导航、焦点提示、模式标识、空状态、输入诊断与带证据边界的 PNG 导出。
开发检查涵盖主视图和完整图的元素一致性、PPI 与靶点关系分别高亮，以及上传文件隔离。
