# 统计方法与推断边界

## 1. 版本与声明范围

本文件描述当前实现的统计合同，而非已经完成的实证验证。

| 项目 | 当前值 |
| --- | --- |
| 软件版本 / 输出 schema | `5.4.0` / `5.4` |
| 研究合同 / 统计合同 | `1.0` / `1.1` |
| 网络方法 | `weighted_fixed_disease_closest_v3_mapped_universe` |
| 可信度公式 | `evidence_credibility_v5_frozen_statistical_targets` |
| 机制规则策略 | `rule_based_mechanism_v3_no_annotation_count_bonus` |
| 独立验证 | 未执行；[协议草案](VALIDATION_PROTOCOL.md)为 `proposed_not_executed` |

输出最多是可审计、规则驱动的 post-hoc 生物学机制假说。`formal_result_eligible=false`
保持不变；当前 production PLATO schema allowlist 为空，真实导入仍会 fail closed。
本次统计合同不批准任何 schema、原始响应或实验结论，也不允许用合成 fixture 替代真实输入。

`network_statistics` 是对外网络统计入口；`mechanism.metrics.cheng` 是保留的兼容字段名。
这个历史名字不表示严格复现 Cheng 等人的方法。输出明确记录
`reference_method_reproduction=false` 与 `biological_interaction_tested=false`。
本方法的距离方向、边权、固定疾病模块以及不相交随机靶点等定义均须以本文件和版本化代码
为准，不能继承参考方法的有效性或已发表的性能结论。

## 2. 分析靶点与选择偏倚

令 A、B 为两个药物通过 PLATO 输入门禁和既定靶点资格规则后，完整 profile 中的去重基因
集合；D 为选定疾病标签对应的冻结疾病基因集合。完整 profile 不是 PLATO 原始响应中所有
未经筛选的条目，论文需同时保存原始响应、资格规则、排除记录和最终集合。

网络统计以 A、B 为资格输入并与冻结 PPI 背景取交集；通路富集与通路背景取交集，而不使用根据疾病/通路上下文排序后截断的
top-k。结果以 `statistical_target_sets` 和
`target_set_scope=complete_input_profiles_before_context_top_k` 记录该边界。
完整输入的顺序或 top-k 变化不应改变这些统计量。模块富集同样从完整 profile 计算。

上下文 top-k 仍用于展示、部分描述性重叠、探索性功能规则及主要机制假说的组织。因此
“整个主机制分类已获得选择校正”仍然是不成立的。PLATO 候选产生、资格过滤、疾病标签
选择和知识库注释本身也可能相关；使用完整集合只移除了这一处 top-k 二次选择，不会自动
消除资源泄漏或其他选择偏倚。

若未来要检验由疾病/通路上下文选出的 top-k，则必须另立方法合同，在每次零模型运行中
重新执行候选产生、评分和筛选，或使用独立数据/合适的选择后推断；当前实现没有完成该校正。

## 3. 加权距离与网络分离度

PPI 上使用加权最短路径距离 `d(u,v)`。边上存在有限正数 `distance` 时优先用该值；否则
以归一化边置信度 c 计算 `1 / max(c, 0.05)`，缺失置信度时使用 0.05。因此“加权”指 PPI
路径代价，不是以 PLATO 分数加权每个靶点。边置信度的原始尺度和加载阈值须随数据配置冻结。

令 V 为加载后冻结的全部 PPI 节点，定义 A_V=A∩V、B_V=B∩V、D_V=D∩V。
V 不随药物对、top-k 或显著性改变；零模型也从同一 V 抽样。以下距离公式中的 A、B、D
均指这些映射后集合。对非空集合 X、Y 定义：

```text
C(X→Y) = (1 / |X|) × Σ[x∈X] min[y∈Y] d(x,y)
d_A_obs = C(A→D)
d_B_obs = C(B→D)
d_AB    = (C(A→B) + C(B→A)) / 2
d_XX    = (1 / |X|) × Σ[x∈X] min[y∈X,y≠x] d(x,y)
s_AB    = d_AB - (d_AA + d_BB) / 2
```

单靶点集合的 `d_XX` 按实现约定为 0。双向跨集合距离对两个方向的均值等权平均，并非将
两个集合的逐节点距离汇总后再平均；集合大小不同时两者一般不同。疾病邻近距离取靶点到
疾病方向，而不是疾病节点到最近靶点方向。

原始 A、B、D 各自的映射比例必须达到配置的 `min_network_coverage`（默认 0.5），
且映射后集合均非空；设为 1.0 可要求完整映射。分母始终是原始集合，不能通过删除记录
伪造覆盖率。结果记录 `analysis_universe` 的节点数量与标识哈希、`analyzed_target_sets`、
`analyzed_disease_genes`、`excluded_unmapped_genes`；原始药物集合仍在 `statistical_target_sets`。
有排除项时标记 `network_analysis_conditional_on_mapped_genes`。节点哈希不包含边及权重，
不能替代上下文 artifact 哈希。该条件分析不声称缺失成员没有生物学作用。

每个映射后观测靶点必须有到 D_V 的有限距离，跨集合及集合内每个需要参与平均的源节点
也必须有有限的最近距离。已映射但不可达的成员不能继续删除来使结果通过；必要距离不完整
或原始覆盖率不足时 `valid=false`、不建立统计支持。

`s_AB` 是描述性几何量，没有独立的协同相互作用检验。当前重叠规则为“存在共同靶点，或
`s_AB<0`”，这是明确的实现约定，而不是经过校准的协同判据。

## 4. 固定疾病模块的自定义零模型

对映射后的 A_V、B_V 分别产生 N 次请求抽样，D_V 始终固定。每次按观测靶点的度逐个抽取节点，不允许
样本包含本次模板中的任何观测靶点，也不允许同一个随机集合重复节点。优先匹配相同度；
候选不足时按 `|log(1+degree_observed)-log(1+degree_sampled)|` 搜索邻近度，最后尝试其他
不相交节点。抽样器的实现和排序规则随网络方法版本固定；这不是均匀抽取所有可行集合的证明。

一次抽样若未达到原集合大小，或任一随机节点不能有限地到达 D，整次拒绝；不能把剩余可达
节点当作完整有效抽样。两侧分别记录请求、接受、拒绝数、拒绝原因、样本大小和派生种子。
`n_valid_randomizations` 是两侧接受数的最小值，不是配对检验的样本数。

每一侧的随机种子由以下记录的 JSON 表示做 SHA-256，并取摘要前 8 字节构造整数：

```text
[network_method_version, base_random_seed, sorted(target_set), sorted(disease_set)]
```

节点、度候选及模板顺序也被规范化。因此同一个目标集合在相同图、D、版本、预算和基础种子
下得到相同零分布；交换药物顺序只应交换两侧统计量。派生种子本身没有包含 PPI 内容哈希，
复现仍需同时固定并记录网络 artifact、依赖和代码版本。

当前 `quality_status=adequate` 至少要求：

- 原始 A、B、D 的映射率达到预设门槛，且映射后全部必要距离完整；
- 请求数至少 1,000，且两侧实际接受数均至少 1,000、均达到各自请求数的 90%；
- 两侧零分布标准差均大于 0；
- 两侧已接受抽样的平均 log-degree 匹配误差均不超过默认 0.35。

预算恰好为 1,000 时，任何拒绝都会使实际接受数不足 1,000。`valid=true` 仅表示观测距离
可计算，不等于零模型质量充分；有限或退化零模型可以保留描述性数值，但不能建立邻近支持。
不能根据结果反复换种子或增加预算直到显著；预算及不充分时的处理须预先冻结。

不相交模板、非均匀的度匹配回退、可达性条件拒绝以及 PLATO 选择流程均可能影响可交换性。
上述质量门槛是工程审慎条件，不是零模型校准证明。当前尾概率只应解释为这个自定义条件
零模型下的探索性极端程度，不宣称已经校准真实世界的频率错误率。

## 5. 尾概率、区间与单对模式

每侧以有效随机距离的均值和样本标准差计算 z；负值表示观测距离比该零模型均值更短。
若 M 为实际接受数、K 为随机距离不大于观测距离的次数，则尾概率估计为 `(K+1)/(M+1)`。
单对的两侧检验做 Bonferroni，`p_adjusted=min(1,2p)`。

Monte Carlo 95% 区间使用原始 K、M 的 Wilson 区间，不将伪计数当成实际试验；调整区间
两端乘 2 后截断至 1。它描述有限模拟的尾部比例不确定性，不是机制真实性置信区间，也
不能补救零模型可交换性不足。

一侧 `near=true` 必须同时满足：零模型质量 adequate、z<0、调整尾概率≤0.05、调整后
Monte Carlo 区间上界≤0.05。没有达到门槛仅表示未建立该条件下的邻近支持。

| 模式 | 当前条件 | 允许解释 |
| --- | --- | --- |
| P1 | 两侧 near，且重叠 | 双药在疾病附近的重叠网络位置 |
| P2 | 两侧 near，且不重叠 | 双药在疾病附近的不同网络位置 |
| P3 | 仅一侧 near，且重叠 | 重叠背景中的单侧邻近；不证明耐药逆转 |
| P4 | 仅一侧 near，且不重叠 | 单侧邻近，不建立双药相互作用 |
| P5 / P6 | 两侧均未建立 near，分别重叠/不重叠 | 描述性几何模式，无邻近支持 |

`statistically_supported` 的当前含义是“至少一侧满足上述探索性条件”。
`both_drugs_disease_proximity_supported` 表示两侧分别满足邻近条件；历史兼容字段
`pair_interaction_supported`（以及外层 `network_pair_interaction_supported`）也仅有这个
含义，绝不是组合协同、药理相互作用或因果机制已经被检验。即使 P1/P2 成立，也不检验
协同相对于相加/拮抗的差异。网络模式只是规则分类的输入，其他探索性规则可能优先决定主机制。

## 6. 通路富集

每个完整靶点集合分别进行单侧超几何过度代表检验。背景是当前加载的全部通路基因并集，
查询集合与该背景取交集；不在背景内的靶点不进入该项检验，不得把它们视为已充分注释。
默认检验通路大小为 5–500，BH 家族包含所有通过大小范围的通路，包括零命中的通路。
紧凑输出可只显示有命中或显著通路；`tested_pathway_count` 才是该次家族大小。

默认以每个药物自身家族的 q≤0.05 选出通路；共享富集表示两侧各自通过门槛，不是一个
独立的组合通路相互作用检验。两个显著通路的笛卡尔配对仍只是描述性注释，不能称为已检验
的通路互补。该局部富集校正不自动覆盖整篇论文的所有药物、疾病或参数网格；通路重叠和
资源相关性也不因调用 BH 而获得验证。

5.3 移除了通路条目数、描述性笛卡尔配对数和共享靶点数在 Jaccard 之外的额外加分。
共享富集规则分固定为 0.52，有合格方向证据的共享抑制规则为 0.60；不同通路注释为 0.35，
且描述性跨靶点距离 d≤3 时为 `0.45+0.05×(3−d)`（上限 0.60）。其余规则阈值和分数仍是
未校准的探索性约定，不能解释为概率或独立证据合成。重复注释或增加展示配对不再直接提高分数。

## 7. 批量网络支持与检验家族

`apply_batch_fdr` 对一个声明批次中的 N 对结果纳入全部 2N 个药物－疾病计划检验。
使用各侧原始尾概率（不再次输入单对 Bonferroni 值）；缺失、非有限、非法概率或不合格
零模型按 p=1 保留，并单独标记不可评估。这些占位检验永远不能建立支持，也不代表真实
p 值已经测得为 1。

BH 输出 `batch_q_A/B`；批量一侧支持还必须保留本地 near 条件。P1/P2 要求两侧通过；
P3/P4 只要求原本获得单侧邻近支持的那一侧通过，不能把另一侧不显著当成相互作用证据。
本地机制原本不受支持时，批量校正不能把它升级为受支持。

家族身份包括规范结构/结构标识、PLATO 导出及靶点哈希、实际统计靶点集合、细胞系、疾病
标签、稳定上下文 artifact 身份和网络方法。家族成员顺序规范化，不以观察到的 p/z/支持
状态、时间戳或本地路径定义身份。记录家族 ID、计划数、可评估数及缺失身份字段；
`identity_complete=false` 不能当作已完成来源审计。家族 ID 也不能替代完整运行配置哈希。

本地 `single_pair_mechanism_supported` 与 `batch_mechanism_supported` 分开。仅网络主机制
才被本项批量支持降级；非网络主机制的 batch 支持为 null，不据此声称它通过多重校正。
局部规则分保持不变，不施加旧的固定扣分；兼容字段 `batch_adjusted_score` 等于本地分数。
分数不变不意味着统计支持不变，报告时必须同时查看两类状态。

“批次”只是函数收到的完整结果集合，不自动等于研究总体。若输入门禁使案例无法生成结果，
须在论文纳入漏斗报告该失败；本函数不会自动得知或补入未传入的研究案例。分析计划应在
查看结果前冻结全部检验家族及技术失败处理，不能只对成功或显著子集调用批量函数，也不能
用拆批规避校正。若另有通路、方向、剂量或多疾病主终点，须另行定义总体检验范围。

BH 通常需要有效的检验 p 值及独立性或适当正相关条件；本函数未验证这些条件。特别是本
项目的自定义条件零模型尚未校准，故目前的 q 值及“支持”应作为探索性统计输出，不宣称
已经实现已验证的研究总体 FDR 控制。

## 8. 敏感性、上游模型与证据维度

top-k 稳定性、靶点删除、模块抑制和路径删除首先是解释器内部的敏感性实验。比较需要
检查原始基线和每次扰动的实际请求/接受预算、零分布质量、方法版本、种子、距离及零模型
协议，不能仅因配置写了 1,000 就称其充分。协议不匹配或零模型不足时可保存前后标签及
规则分变化，但应标为描述性/不可比较，不作为充分稳健性加分。

完整统计输入在 top-k 变化中保持不变时，网络统计恒定是设计结果，而不是对网络推断的
独立压力测试。不能据此证明网络机制稳健；仍需预先定义真正改变网络、数据、输入或规则的
敏感性分析。非网络主机制的 top-k 一致性也只能作描述，不自动享有网络零模型的有效性。
即使某项内部比较合格，也不等于通过外部验证。

删除解释器里的靶点、通路成员或网络边，不代表实际敲除/抑制药物作用，更不等于上游协同
模型重算。没有运行模型 evaluator 时，`predicted_synergy` 仅被记录。调用方提供的模型
扰动记录须与原始预测相符，不能用其 `provided_prediction` 覆盖原始基线；重复语义身份
或重复扰动 ID 不计为独立扰动，缺少身份的记录仅作描述。即使通过内部数量、方向和变化
幅度门槛，调用方证据仍标为 `caller_supplied_unverified`、`independently_validated=false`，
不能当作已校准或独立验证的忠实度证据。

论文应至少分开呈现四类信息：输入/来源完整性，规则与条件零模型支持，实际敏感性，独立
外部验证。`mechanism_confidence` 和 `evidence_credibility_score` 都是未外部校准的规则分，
不是机制真实概率；完善审计或提高分数本身不能补上验证证据。

单侧网络模式的规则支持按其单侧条件判断，不要求另一侧同时显著；双侧邻近另行报告。
同一个网络命中不再作为额外的“证据汇聚”奖励。其余分项仍可能共享资源或相关信息，
不能把分项数量解释为独立证据数量，也不能把规则分的加和解释为概率合成。

5.4 的文献角色层补充药物特异的药效/药物处置注释和叙述，不改变本统计合同 1.1 的
候选集合、网络方法、零模型、富集 p/q 或分数。文献锚定是注释输入，不能同时当成独立
验证结果；详见[文献角色方法](PHARMACOLOGY_ROLES.md)。

## 9. 复现、历史结果与待完成工作

保留原始 PLATO 响应和独立审批记录、资格过滤结果、完整统计靶点、网络/通路/疾病 artifact、
代码快照和依赖、配置/种子/预算、局部和批量状态、纳入失败及敏感性明细。JSON canonical
哈希与落盘字节 sidecar 是完整性记录，不是来源真实性或科学有效性的证明。

5.2 及更早结果使用了不同的映射范围、评分规则或质量判定，必须从合格原始输入在当前版本重跑，
不能只改 schema、公式名或历史 `valid` 标记。档案继续保留，不自动视作当前回归基线。

下一阶段需按[独立验证协议草案](VALIDATION_PROTOCOL.md)冻结研究案例、数据和规则，完成
来源审批、独立留出、盲评、相加/拮抗对照、资源消融及预定义敏感性；必要时校准或替换零模型
及多重检验策略。本文件不声称这些步骤已经执行。自动化测试只验证软件合同中的特定行为，
不能证明真实机制或使当前生产门禁开放。
