# 机制假说模块独立验证协议（拟议，未执行）

> **历史可选扩展，非当前毕业论文验收要求（2026-10-13）。**
> 当前以 [工程验证方案](ENGINEERING_VALIDATION.md) 为准，验证可用、可追溯、合理响应输入变化。
> 不要求独立双人评阅；仍不能把开发案例演示称为独立机制验证。本草案未被执行或追认通过。

- 协议版本：`1.0-draft`
- 状态：`proposed_not_executed`
- 适用范围：可审计的 post-hoc 生物学机制假说，不是协同模型归因、因果机制证明或临床验证。
- 本文件是待冻结的分析计划，不代表已经获得独立数据、完成实验或通过验证。

声明边界遵循 [论文机制假说模块范围](THESIS_INTERPRETATION_SCOPE.md)。当前 production
PLATO schema allowlist 为空，真实导入仍须 fail closed；不得为开展评测绕过门禁，或把
测试 fixture 改标为真实案例。当前合同中的 `formal_result_eligible=false` 保持不变；
研究论文可以报告经审计的假说和评测，但不能据此升级为正式机制结论。

## 1. 研究问题与冻结条件

主问题：相对于只使用 PLATO 靶点的基线，上下文整合能否增加与独立证据一致的候选机制，
同时控制无证据输出和错误的协同机制声明？次问题：结论对合理参数及数据扰动是否稳定？

正式评测前须填写并锁定样本量及其理由、开发/留出分组、主要终点、比较方法、置信区间
方法、随机种子、随机化预算、敏感性参数网格和多重检验集合。尚未填写或未签署冻结记录时，
仅能进行流程试运行；试运行案例不得再作为未见过的正式留出集。

冻结包至少包括：

- 原始输入及合法取得的 PLATO 单药响应、独立来源审核和 schema 审批记录、SHA-256 清单；
- 化合物标识/结构、细胞系、疾病、剂量、处理时长和协同评价定义；缺失项逐项记录；
- PPI、表达、通路、疾病资源及其版本、许可、原始文件哈希和处理脚本；
- 代码版本及实际源码快照哈希、环境锁定、有效配置、机制规则、阈值、权重和方法版本；
- 独立验证证据清单、检索截止日、标注表、盲评规则，以及各文件与案例的对应关系。

任何冻结后的变更均保留旧版本、说明原因并生成新协议版本。不得根据留出结果调参后仍将
同一批案例称为独立验证；新增分析明确标为探索性。

## 2. 全部输入的纳入与排除流程

分析单位为“无序药物对 × 生物学上下文 × 实验条件”。同一药物对的重复文献或测量不得
作为独立案例重复计数；聚合方式及相冲突证据的处理须预先定义。

为每个候选建立不可变案例 ID，并报告逐级数量及原因：

1. 检索/收集到的全部候选；记录来源与去重结果。
2. 可核对结构、上下文和实验终点的候选；缺失条件不能靠推断补齐。
3. 具有合规归档且通过独立审核的双药 PLATO 输入；记录每一道门禁的失败原因。
4. 满足预定义靶点与上下文数据质量要求的候选。
5. 成功运行、技术失败和主动拒答的案例，分别列出。
6. 输出可供盲评的假说，以及无法判定或证据冲突的案例。

报告两类覆盖率：相对全部去重候选的端到端覆盖率，以及相对通过输入门禁案例的条件覆盖率。
不得把输入失败、缺证据或拒答案例静默移出总体报告，也不得只纳入高分或解释漂亮的案例。
当前门禁关闭时，真实分析阶段状态应报告为“未开展”，不是“验证通过”。

## 3. 独立留出与证据标注

开发集用于规则构建，留出集仅用于冻结后的最终评测。按药物分组留出；另设骨架留出分析，
结构标准化和骨架定义随协议冻结。同一药物、别名、盐型以及预定义等价结构不能跨越对应
分组边界；无法同时满足的跨组药物对单独排除并报告，不进行随机拆对来制造独立性。

验证证据须尽量来自未参与规则、PPI/通路注释或靶点资源构建的原始干预研究。逐条检查
其文献来源与开发资源的重合；同一知识库事实的重述只能算资源一致性检查，不能算独立
机制验证。无法确认独立性的案例降为次级分析并明确标记。

标注时分开记录：

- 组合表型：协同、相加、拮抗或不可判定，附实验条件、原始数值和评价准则；
- 机制证据：干预支持、关联支持、相矛盾、证据不足，以及具体靶点、方向和适用上下文；
- 独立性与证据质量：原始研究来源、资源重合和冲突情况。

至少两名评审按预先定义的匹配标准盲评，隐藏模块分数、方法组别和开发人员判断；保留
独立初始标签、分歧及裁决。仅名称相似或通路重叠不能自动视为机制命中。

## 4. 对照与消融

必须纳入有实验依据、上下文可比的相加及拮抗组合，用来检查系统是否对任何组合都给出
协同机制叙述。“机制未知”不等于负例；相加/拮抗也不意味着所有生物学机制假说为假。
分别评价表型声明是否越界和候选机制是否获得独立支持。

所有方法使用相同的合格 PLATO 输入与冻结案例，至少比较：

| 方法组 | 用途 |
| --- | --- |
| PLATO 靶点基线，不进行上下文重排 | 测量靶点证据本身能够支持的解释 |
| 完整上下文模块 | 待评估方法 |
| 分别移除表达、疾病、通路信息 | 估计各资源的增益及覆盖率代价 |
| 预定义随机对照 | 检查几何结构或筛选流程本身能产生的支持 |

消融只能移除信息，不能从其他来源补入药物靶点或改变 PLATO-only 合同。输入完整性审计
独立于资源消融；不适用的终点记为不可评估，不当作零分。记录缺失资源导致的拒答，并在
相同案例上作成对比较，防止仅比较各自成功子集。

## 5. 统计推断与选择过程

当前 5.4 / 统计合同 1.1 的网络与通路统计使用预先冻结、未经上下文 top-k 截断的完整合格
PLATO 靶点集；上下文 top-k 用于展示及探索性规则。具体定义见[统计方法合同](STATISTICAL_METHODS.md)。
这一分离不代表整个规则分类、PLATO 筛选或知识库来源已经获得选择校正。若要对上下文筛选后的
top-k 作推断，每次随机对照必须重跑候选构造、上下文评分、
top-k 选择及统计计算，而非只随机替换最终靶点。

冻结距离方向、边权含义、网络分析范围、度匹配规则、可达性条件和抽样拒绝政策。不完整
随机集合不得通过静默删点变成有效样本；报告请求、接受、拒绝数及原因，并为不足预算、
零方差和不可达观测设置不可推断状态。自定义距离/零模型明确命名，不能继承参考方法的
验证结论。

多重检验范围按预注册的案例、方向和终点整体固定，不按文件或运行批次重新定义。
单对检验和校正后的支持状态分开报告；不同机制使用各自预定义的支持条件，不以固定扣分
代替统计判定。将预测分数的事后记录与模型扰动评测分开：后者必须绑定原始预测、模型版本
和唯一扰动 ID，且只支持“模型行为一致性”结论。

## 6. 终点与报告

| 指标 | 分母与解释 |
| --- | --- |
| 覆盖率、技术失败率、拒答率 | 同时报全部候选及门禁合格集；区分不可运行与运行后拒答 |
| 独立证据一致性 | 在独立可判定且实际输出的假说中，报告支持、矛盾、部分支持；同时报告不可判定数 |
| 支持假说的总体产出率 | 独立支持的输出数 / 预先确定的可评价案例数，避免靠大量拒答抬高一致率 |
| 对照上的越界声明率 | 在已验证相加/拮抗组合中，报告无相应证据却声明协同机制的比例 |
| 稳定性 | 预定义扰动下的机制标签一致率、靶点/路径集合重叠、拒答转变及有效运行数 |
| 评审一致性 | 报告裁决前一致率、适用的一致性统计量和分歧类型 |

缺少足够独立可评价证据时，报告描述性结果及不确定性，不填补为“正确”或“错误”。
方法比较采用预先冻结的成对分析；同药物/骨架及重复上下文的相关性必须纳入区间估计或
分组汇总，不能把它们当完全独立样本。

稳定性网格至少覆盖 top-k、PPI 阈值、疾病集、表达上下文和随机种子；替换后的细胞系应
被视为上下文特异性对照，不要求机制必须不变。每次运行均报告实际随机化预算、零分布
质量和失败状态，不能用计划参数代替执行证据。

当前网络统计的输入不随 top-k 改变，因此其恒定性只能作描述，不能计为独立网络稳健性。
须使用真正改变统计输入或网络的预定义扰动；自定义条件零模型的校准仍需单独验证。

规则得分、审计完整性及稳定性分别呈现，不解释为机制真实性概率。结果表保留支持证据、
反证、未知作用方向、适用条件和待验证预测，不仅展示支持性链条。

## 7. 完成判据与交付

本协议完成验证需具备：已签署冻结包、真实输入审批、完整候选流程表、独立盲评记录、
所有基线/消融/对照输出、统计分析与敏感性报告、可重运行环境及逐结果哈希核验。
自动化单元测试通过只代表软件行为满足测试条件，不替代以上验证。

最终报告须明确区分软件测试、真实数据试运行、独立机制评测和未来实验验证。任何未执行
部分保持“未执行/待完成”；本协议不会自动授权开放门禁、批量查询外部平台或生成实验数据。
