# InterpreterPLATO 后续实验执行细则

> **2026-10-13 范围调整：以下为保留的可选独立研究草案，不再是当前毕业论文必做清单。**
> 当前执行 [工程验证方案](ENGINEERING_VALIDATION.md)：既有六个开发案例、来源审核、
> 可用性/可追溯性测试及显式输入控制；不要求独立双人机制评阅，不宣称独立机制准确率。
> 真实 PLATO 来源门禁不变；此调整不表示已完成真实案例验证。

版本 `1.0-draft`；日期 2026-09-09；状态 `proposed_not_executed`。
本文件将 [独立验证协议](VALIDATION_PROTOCOL.md)细化为工作量和记录格式，不替代
[论文范围](THESIS_INTERPRETATION_SCOPE.md)或 [统计合同](STATISTICAL_METHODS.md)。
所有案例数量、参数网格都是拟议预算，须在开发阶段确认可行性后冻结；尚未取得真实验证结果。

## 1. 目标与当前依赖

目标：评估可审计机制假说的覆盖、证据一致性、越界声明和输入/资源敏感性。
这是独立课题的核心验证，不仅是预测模块的案例展示。

当前 schema 为 5.4；production PLATO schema allowlist 为空。真实案例输出前须完成
既定的来源审核、双药 raw-SHA/结构绑定以及 schema 审核。计划不授权修改 allowlist，
也不将当前 `formal_result_eligible=false` 改为 true。

可立即准备：离线审计测试、候选清单、去重/分组、证据表、评阅标准、预算和自动分析器。
需真实输入审批后执行：真实研究模式下的 baseline、消融、敏感性和盲评输出。
合成 fixture 的通过率只计软件指标，不计真实案例覆盖率或独立机制支持率。

## 2. 案例登记与留出

### 2.1 数量和纳入流程

目标先整理 36 个独特“无序药物对×上下文×实验条件”案例：12 个开发、24 个留出。
这是可行性预算，不是统计功效计算。按药物及等价结构分组，任何药物/别名/预定义盐型
不得跨开发/留出边界；不满足时补充候选并保留排除记录。骨架留出只在案例足够时作为
独立次级分析，不把相同药物的重复测量算成新独立样本。

留出目标配额：8 个有实验协同表型、8 个有实验相加/拮抗表型（尽量各 4 个）、
8 个机制证据不足或存在冲突的案例。采用上述顺序分配互斥配额：先登记未知/冲突组，
再在剩余案例中分配两类已知表型组；完整表型标签另列，不以配额名称代替表型。
机制支持状态与组合表型分别标注；“相加/拮抗”并不表示任何机制假说都是假。

保留全部收集候选的登记记录；结构/剂量/时长/细胞系缺失分别标注，不靠常识补齐。
不能因模块低分、拒答或不一致删例。最终有效数不足目标时，报告实际分母及原因；可以
在读取模型输出前按原纳入规则补充候选，但看过输出后不得为改善指标替换案例。

### 2.2 独立证据

开发案例可用于明确规则、显示模板和参数可行性；留出案例不得用于这些选择。
记录原始论文、证据类型、实验干预、上下文、方向及出处段落。核对其是否参与 PLATO、
STRING、Reactome、COSMIC 或当前规则开发；同一资源事实的重复陈述只作资源一致性。
无法核实独立性的证据标为次级，不写成独立机制命中。
“独立可评价”标签在看输出前确定，决定主要证据评估分母。

登记表拟定字段：

`case_id, drug1_id, drug2_id, canonical_structures, cell, disease, dose, duration,
phenotype_definition, phenotype_label, evidence_label, source_id, evidence_locator,
development_overlap, evaluation_eligibility, partition, inclusion_status, exclusion_reason,
plato_input_gate_status, raw_sha256_A, raw_sha256_B`。

## 3. I0：审计与异常行为

| 场景 | 预期行为 | 验收 |
|---|---|---|
| schema 未批准、双药哈希缺失、结构不匹配 | 拒绝相应真实研究输出并给原因 | 不能升级为合格研究结果 |
| 资源字节被修改、锁文件不一致 | 完整性错误可追溯 | 保留失败记录 |
| 未知细胞系、靶点无可用映射 | 按既定合同拒答或不可评价 | 不静默用替代上下文建立支持 |
| PPI 不可达、零模型不足或零方差 | 统计不可推断；保留允许的描述字段 | 不产生充分网络支持 |
| 无独立模型 evaluator | 标记模型忠实度未评估 | 不宣称解释了预测分数 |
| 同输入/资源/种子重复运行 | 科学字段可复现 | 时间戳等运行字段单独处理；不要求整份含时间 JSON 字节相同 |
| 药物顺序交换 | 无序组合假说一致，两侧身份正确交换 | 显式记录有序字段而非整体文本机械相等 |
| 批量成员中存在失败/不可评估项 | 保留预定检验家族及漏斗记录 | 不按成功子集偷偷缩小分母 |

对上述合同性错误，拟定验收为全部预期行为满足；这是软件验收标准。生物学一致率没有
预先保证通过的阈值。已存在的回归测试可复用，但结果须由当前源码实际运行获得。

## 4. E13：基线与资源消融

冻结留出名单后，同一批 24 案例执行 7 种配置，计划 168 个配置输出（含拒答/失败记录）。

| 配置 | 改变内容 | 比较目的 |
|---|---|---|
| full | 当前冻结的完整研究模式 | 主方法 |
| plato_ledger | 仅列合格 PLATO 靶点及其原始支持信息 | 数据来源基线；不伪造缺失的机制推断 |
| raw_rank | 使用 PLATO 原排序，后续解释组装使用同样资源 | 检验上下文重排的增益；不称为无上下文模型 |
| no_expression | 不使用表达证据 | 表达层贡献及覆盖代价 |
| no_disease | 不使用疾病集/疾病加权 | 疾病层贡献；疾病邻近统计记不可评价 |
| no_pathways | 不使用通路证据 | 通路层贡献 |
| no_ppi | 不使用 PPI 网络证据 | 网络依赖与拒答行为；网络终点记不可评价 |

受控消融必须有显式研究实现和独立配置身份。不得直接删/改锁定资源文件来绕开完整性
检查，也不得通过其他来源补入新药物靶点。若当前严格运行合同不能生成某消融输出，记为
实现前置问题/拒答覆盖结果，不擅自把该配置“降级跑通”后与完整模式合并。

plato_ledger 可能无法输出机制假说，其机制终点为不可用；该比较说明新增模块提供了什么，
不能据此声称战胜一个同等功能的机制算法。full 与 raw_rank 的共同终点才用于上下文排序比较。
各配置统一表格模板、证据单位及最大展示条数，隐藏配置名供盲评，报告者不得现场润色有利文本。

主比较先固定为 full vs raw_rank 的独立支持假说总体产出率差；其他消融为次级描述分析。
若 raw_rank 无法合法实现，须在看留出输出前修改并重新冻结主比较，不能运行后挑最佳对照。

## 5. E12：真正的输入与资源敏感性

一次只改一个因素，避免一开始全组合。基础随机种子暂定 42；主运行每侧请求随机化
预算暂定 2000。按当前统计合同报告实际接受/拒绝数及零模型质量；请求 2000 不保证充分，
不充分不重新抽到显著才停止。

| 因素 | 拟定设置 | 解释边界 |
|---|---|---|
| top_k | 基础 10，另做 5、20 | 靶点不够时用实际数量；网络完整靶点集未变的恒定性不计稳健性 |
| 网络随机化种子 | 基础 42，另做 43、44、45、46 | 改模拟随机性，固定预算和其他输入 |
| PPI 边阈值 | 基础 t0，另做归一化置信度 t0±0.1，裁到 [0,1] | 先验证源数据包含所需边；新 artifact/manifest，不能从稀疏图虚构被删边 |
| 合格 PLATO 靶点删减 | 每侧删除最多 floor(0.1×n) 个，保留至少 1 个；3 个固定扰动种子 | 只删除原合格集合成员；由记录的研究扰动实现，禁止绕过输入来源合同 |
| 排序权重 | 全部非 PLATO 上下文权重乘 0.8 / 1.2 后按既定方式归一化 | 只影响实际依赖这些权重的终点；不把重排当成来源变更 |
| 疾病集合 | 1 个预先指定且有出处的替代集合 | 敏感性分析，不保证机制恒定；禁止按支持度选疾病 |
| 细胞系上下文 | 1 个预定、数据已加载的不同细胞系 | 上下文特异性对照；改变结果可能合理 |
| 药物顺序 | A/B 交换 1 次 | 对称性/字段归属检查，不计生物学稳定性 |

全可行时额外次数为 2+4+2+3+2+1+1+1＝16/案例；24 案例最多新增 384 个配置。
与 E13 合计最多 552 个配置输出。不同配置可能复用相同统计输入的缓存，应按实际唯一
输入/资源/种子/方法/预算哈希计计算数；缓存命中不是独立重复。
网格因数据不可用而缩减，须在开发集阶段记录并冻结，不能根据留出支持率缩减。

终点：机制类别一致率、靶点/通路集合 Jaccard、共同靶点上的排序相关、支持状态变化、
拒答转变。两集合都空时 Jaccard 记 NA 并计数，不当作完全稳定；靶点不足以计算相关时同理。
对真正改变完整统计靶点或图的配置，另报距离、z、尾概率、MC 区间及支持状态变化。
若删减没有实际删除任何靶点或阈值裁剪导致图未变，则标无效扰动，不凑稳健性次数。

疾病和细胞改变通常检验上下文特异性，单列变化方向，不能按“不变越多越好”统一评分。
改变 predicted_synergy、但未改变解释输入或接入 evaluator 的重复运行，只作为字段/接口检查。

## 6. E14：双人盲评与指标

两名评阅者先在开发集上校准评分标准，保存各自原始标签。正式留出阶段隐藏 ScoreRI
分数、方法组别及规则支持分，随机分配展示顺序。内容可能使评阅者猜到方法，应在限制中说明。
依独立证据先评事实，再评假说支持；有分歧时由双方讨论或第三人裁决，初始标注不得覆盖。

| 评阅维度 | 记录值 |
|---|---|
| 来源可追溯性 | 可定位 / 部分可定位 / 不可定位；列缺失字段 |
| 对独立证据的匹配 | 支持 / 部分支持 / 矛盾 / 不足以判断 |
| 上下文与作用方向 | 相符 / 冲突 / 未知；给原始证据定位 |
| 表述是否越界 | 无 / 协同表型越界 / 模型归因越界 / 因果或临床越界 |
| 输出状态 | 成功输出 / 科学拒答 / 输入门禁失败 / 技术失败 |

主计数先按案例而非文本句子定义：每方法每案例最多评 3 条按固定规则选出的核心假说。
一个“支持案例”要求至少一条核心假说获独立支持，并且其他核心假说中无明确矛盾；
部分支持、不足判断及相互矛盾单独计。该聚合定义在开发阶段冻结。

报告分母：

- 端到端覆盖率＝真实有效输出案例数 / 全部冻结留出候选数。
- 条件覆盖率＝输出数 / 双药输入门禁合格案例数；同时列该分母与全部候选数。
- 支持假说总体产出率＝独立支持输出案例数 / 预先标注的独立可评价留出案例数。
  该分母不因方法拒答而缩小；输出方法之间成对比较。
- 输出内一致率＝支持案例数 / 独立可评价且实际输出的案例数；与总体产出率一起报告。
- 越界声明率＝有越界声明的案例数 / 预定可评价案例数；在已知相加/拮抗组另列。
- 对矛盾、未知、输入失败、技术失败分别列数量，不能都算“不支持”。

先报告裁决前原始一致率及分类混淆表，类别分布允许时再报告 Cohen's kappa；退化时记 NA。
成对效果区间可按共享药物形成的连通案例簇 bootstrap（拟 B=2000，seed=9042）；若簇数
过少则只给原始计数和逐簇结果，不按 24 案例独立假设制造精确区间。24 案例是小样本
可行性评测，不宣称机制准确率已经外部校准。

## 7. 统计家族、案例展示与算力

按冻结的案例/疾病/方法配置预先列出全部计划检验。主 full 配置的 24 案例有 48 个计划
药物－疾病侧检验；其他消融/敏感性不能用于挑显著结果替代主配置。跨配置的推断如要合并，
必须预先定义完整家族并实现；当前 batch 函数仅校正传入批次，不能自动完成论文级处理。
零模型可交换性及 BH 适用条件尚未独立校准，q 值仅作合同允许的探索性支持。

论文展示从登记阶段预选 6 个代表案例：2 个协同、2 个相加/拮抗、2 个未知/冲突，均附
原始输入、支持链、反证、限制和可测试预测；详细定量统计仍包含整个留出集。
不能运行后只选“解释漂亮”的结果。ScoreRI 分数用于记录候选来源时同时绑定 checkpoint、
split 和样本 ID，不作为机制独立证据或病例生物学真值。

计算预算先在 12 开发案例中测真实用时、内存、缓存命中和失败率，再估算 168+最多384
个留出配置的成本。无需把每次配置都算成重新查询 PLATO；相同合格单药归档按合同复用，
不自动增加外部请求。人工首轮评阅上限为 168 输出 × 2 人＝336 份；随机扰动以分析表汇总，
仅对预定异常样本安排额外复核，所有抽检规则先冻结。

## 8. 交付和验收

交付文件约定：`protocol_freeze.json`、`case_registry`、`evidence_registry`、`reviewer_1/2`、
`adjudication`、`eligibility_flow`、`configuration_manifest`、各解释 JSON/sidecar、
`ablation_summary`、`sensitivity_details`、`audit_failure_report` 和来源/版本清单。
这些是待生成的记录，不是当前已存在的实验产物。

完成判据：候选完整登记、开发/留出分组可核验、真实输入满足合同、预定基线/消融与敏感性
都有输出或失败说明、双人原始标签可追溯、分母/统计家族明确、结果可由冻结输入复现。
软件测试完成、真实数据试运行完成、独立假说评测完成分别报告；不能用其中之一代替另一个。
独立证据不足或来源审核未完成时，明确未完成部分；既不将未知当负例，也不补造案例。
