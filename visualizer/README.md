# InterpreterPLATO Visualizer

轻量、纯前端、可离线运行的解释 JSON 查看器。无需部署模型、Python 服务或数据库。

## 直接使用

下载仓库源码后，双击本目录的 `index.html`，并保留同目录的 JS、CSS 和 `vendor/` 文件。
浏览器会先显示 **Dabrafenib + Trametinib** 的文献导览实例（非模型计算结果）。
可切换到“合成测试 · 功能边界”；点击 **打开 JSON**，或拖入本地文件，
即可查看已有解释。支持单条解释、解释数组，以及 `{"results": [...]}`。

文件只在当前浏览器内通过 File API 读取。应用不向服务器上传数据、不查询 PLATO、
不下载原始生物医学资源，也不重新运行解释器。Cytoscape.js 已随目录打包，没有 CDN、
远程字体、分析脚本或运行时安装步骤。已有 Python 环境也不是查看器的运行前提。
离线交互不发起网络请求；只有主动点击来源卡片的外部链接时才打开来源网站。

默认视图先展示双药、MEK1 / MEK2、BRAF 和疾病模块共 6 个节点：2 条已有 PPI、
3 条靶点关联、1 条疾病背景归属。从左向右经 BRAF 读到最右侧的**疾病模块**。
疾病模块保留“黑色素瘤 · BRAF V600 文献背景”标注，不冒充计算得到的疾病基因集。
BRAF 是中间的关键节点，不是两种药物的共同直接靶点；阅读顺序不代表作用方向。
点击“完整网络”可查看全部 11 个节点、9 条有记录的蛋白互作、6 条选定路径；数据不被裁剪。
实例提供“靶点／连接／背景”导览和固定布局，使用公开 UniProt / Reactome 注释与原始研究链接，不分发 COSMIC 等受限
上下文。完整来源、署名、选择规则和限制见 [文献实例说明](REFERENCE_CASE.md)。

## 功能

- 根据 `evidence_graphs.explanation_evidence_graph.nodes/edges` 展示既有证据图。
- 节点搜索、节点类别与边类别筛选、全景／力导向／层次／同心／网格布局、缩放和平移；搜索后按 Enter 查看节点详情。
- 高亮 `local_evidence.cross_drug_paths` 与 `local_evidence.top_paths` 的已有 PPI 边。
- 区分共享节点零跳、疾病成员零跳和非零跳路径。
- 悬停／点击查看原始属性与来源；独立诊断面板保留上游未映射、断连和展示限制信息。
- 完整网络以小节点和淡连线呈现，默认不显示节点标签；悬停浮卡显示名称、类型和可见连接数，并突出已有直接邻居。核心路径仍显示标签。
- 选择批次中的单条记录；失败记录仍可查看诊断，不伪造空机制。
- 导出带运行模式和解释边界标识的 PNG。

界面采用深色导航与路径栏、暖白网络画布、编辑式大标题和少量酸橙色强调。
参考 Linear 的界面层次与 Rive 的画布工具布局，保留独立的项目品牌与实现；
参考链接和具体取舍见 [设计说明](DESIGN_NOTES.md)。

- 左侧通过“路径／筛选”标签切换内容；画布左上角可收起整栏，保留筛选状态。
- 详情默认收起；点击节点、边、路径或“详情”按钮展开。空图记录自动打开诊断。
- 画布右下角提供放大、缩小与适配视图；图例区分边的关系与基因靶点归属。
- 标签支持左右方向键、Home／End；详情面板内按 Escape 关闭并返回触发按钮。
- 小屏幕优先显示画布，路径与详情排列在画布下方。

上限为 20 MiB JSON、100 条解释、每条 5,000 个节点和 20,000 条边。
这是面向结果文件的轻量查看器，不是原始数据库或大规模全网络浏览平台。
完整网络默认使用轻量全景布局，按当前可见连接数排序后紧凑排布；同心、层次、网格与力导向布局仍可切换。超过 400 个可见节点时，力导向布局会回退到全景布局。位置只服务于显示，不表示生物学机制或已计算的聚类。

## 证据与视觉语义

| 关系 | 样式 | 解释 |
| --- | --- | --- |
| `PPI` | 青绿色实线、无箭头 | 输入文件记录的无向 PPI 连接 |
| 候选靶点关联 | 金色虚线、无箭头 | 文件中的药物—候选靶点关系 |
| 疾病／通路集合归属 | 紫色点线、无箭头 | 集合成员关系，不是 PPI 或作用方向 |
| 证据／报告结构 | 灰色虚线、默认隐藏 | 证据支持、报告归属或敏感性记录 |
| 动态假说 | 粉色虚线、默认隐藏 | 规则生成假说，不解释为已验证的因果作用 |
| 未识别类型 | 灰色关系、默认隐藏 | 保留原类型并提示，不归类成 PPI |

查看器不根据路径列表、节点位置、相近名称或示意图推断、补全任何关系。
一条路径缺少节点或对应 PPI 边时，路径仍列出诊断，但禁用高亮；不自动补边。
无证据图的旧结果会明确提示缺失，不从靶点列表拼出一个网络。
重复节点 ID、悬空边、有向／自环／非基因 PPI 作为输入错误拒绝展示。

上游 `build_evidence_graph` 会检查路径是否存在于其加载的 PPI 图中；前端只能呈现
JSON 中的记录，**无法独立核验上传文件的真实性、上游原始数据或再分发授权**。
界面和 PNG 均保留这一边界；图中连通不构成真实机制、协同、激活／抑制或因果证明。

可选合成测试示例的药物、`SYN_*` 节点、PPI、通路与诊断均为手工构造的合成占位：
`run_mode=test`、`generated_from_test_fixture=true`、`formal_result_eligible=false`、
`metadata.conceptual_example=true`、`metadata.calculation_performed=false`。
它只演示交互功能，明确标注“概念示意（非真实计算结果）”，不冒充真实 PLATO 预测。
真实输入的测试模式会显示为测试模式，不会因 `run_mode=test` 就被改称合成数据。
文献实例单独使用 `run_mode=reference_example`、`calculation_performed=false`，不称为合成
生物学数据，也不冒充模型结果。其“疾病”节点仅是单基因文献背景，界面按此名称呈现。

## 可选：构建单文件 HTML

开发者安装 Node.js 22 或更高版本后，从仓库根目录执行：

```bash
node visualizer/build.cjs
```

输出到 `visualizer/dist/InterpreterPLATO-Visualizer.html`。将这个单文件交给其他人后，
对方双击即可打开，无需 Node.js、Python、其他资源文件或网络连接。
第三方库的 MIT 许可证同时保留在单文件中。

## 将已有实际运行结果制作成本地实例

查看器也支持在同一个离线 HTML 中内置多份已完成的解释器输出，通过右上角选单切换。
这与文献导览是独立的实例类型：不重新运行 PLATO，不修改结果字段，不将开发测试改称正式验证。

```bash
node visualizer/build.cjs --case /absolute/path/explanation.json --output /local/output/run-viewer.html
```

重复 `--case` 可将多例结果放进同一个网页，无需逐个上传文件：

```bash
node visualizer/build.cjs --case /local/case-a.json --case /local/case-b.json --output /local/output/run-suite.html
```

默认从两种药物各选一条有完整靶点边、PPI 和疾病集合归属的非零跳路径；
某侧没有这类已记录路径时，使用已有的零跳疾病集合成员记录，不伪造自环或 PPI。
也可重复指定 `--focus-path disease:3 --focus-path disease:6`，选择原输出中的路径索引。
这些参数只作用于其前面最近一次 `--case`，每例可单独选择路径。
所选路径必须已经存在，缺边时构建失败，不补边。
默认核心图展示药物、候选靶点和已有 PPI 路径，不重复绘制共同的疾病集合终点。
集合名称、来源和规模保留在结果详情中，“完整网络”可查看原有集合节点及归属边；
不得将泛癌集合改称细胞系特异集合。

页面分别展示探索性规则分类、疾病邻近检验的校正 p 值，以及调用方提供的上游输入分数。
上游分数不会被标为本次解释器新计算的协同分数。未知统计状态显示“未记录”，
统计无效时显示“不可评估”，单侧疾病邻近支持不改称双药作用或协同得到支持。
主图只筛选显示范围；“完整网络”保留全部原始节点、边和报告结构，来源面板保留输入文件 SHA-256。
自行上传的 JSON 不能通过同名元数据启用内置布局或伪装成这个实例。

构建器只读取本地输入并写入用户指定的输出位置，不创建公开数据文件，也不上传。
含 COSMIC、PLATO 导出或其他受限注释的真实运行实例应保留在本地许可范围内，
公开仓库只提供查看器与构建代码；`visualizer/dist/` 已忽略，运行 JSON 不作为公共测试夹具提交。

## 开发检查

```bash
npm ci --prefix visualizer --ignore-scripts
npm test --prefix visualizer
```

运行时只有已打包的 Cytoscape.js；`jsdom` 仅用于开发期 DOM 交互测试。
测试涵盖图的完整性、路径不补边、零跳、无箭头视觉规则、输入上限、批次失败记录、
本地文件读取、文本安全、布局交互、面板状态、键盘导航、缩放边界、模式标识和单文件构建。
文献实例额外检查冻结 JSON 一致性、逐边互作记录、背景归属范围、疾病主路径／完整网络切换、
真实药物靶点边高亮、导览操作及上传文件隔离。
DOM 与 Cytoscape headless 测试不能替代真实浏览器的 Canvas 和视觉验收。
